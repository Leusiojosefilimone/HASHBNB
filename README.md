🏠 Airbnb Clone — MERN Stack

Projeto desenvolvido com o objetivo de praticar e consolidar conhecimentos da stack MERN, inspirado na plataforma Airbnb.

Este projeto foi desenvolvido durante os meus estudos de desenvolvimento web, acompanhando conteúdos do canal Hashtag Programação e adaptando os conhecimentos adquiridos para construir uma aplicação completa.

⚠️ Nota: Este projeto é exclusivamente educacional. Não possui qualquer relação oficial com o Airbnb e foi criado apenas para fins de aprendizagem.

🚀 Tecnologias utilizadas
MongoDB — Base de dados
Express.js — Framework para criação da API
React.js — Desenvolvimento da interface
Node.js — Ambiente de execução do backend
JavaScript
HTML5
CSS3
Git/GitHub


O projeto simula algumas das principais funcionalidades de uma plataforma de alojamento:

🏠 Visualização de alojamentos
🖼️ Apresentação de imagens
📄 Página de detalhes do alojamento
🔐 Autenticação
📡 Comunicação entre frontend e backend através de API
💾 Persistência de dados com MongoDB
🧠 Objetivos do projeto

O principal objetivo foi colocar em prática conceitos fundamentais do desenvolvimento full-stack, incluindo:

Criação de aplicações com React
Desenvolvimento de APIs REST
Integração entre frontend e backend
Operações CRUD
Modelagem e utilização de bases de dados
Autenticação de utilizadores
Gestão de estado
Estruturação de um projeto full-stack
Consumo de APIs
Organização de componentes React


📚 Aprendizagens

Este projeto foi importante para compreender melhor como diferentes tecnologias podem trabalhar juntas numa aplicação real:

React
   ↓
API REST
   ↓
Node.js + Express
   ↓
MongoDB

Também serviu para desenvolver uma visão mais completa sobre o processo de criação de uma aplicação web full-stack.


Sobre o projeto

Este projeto faz parte da minha jornada de aprendizagem em desenvolvimento web full-stack, com foco na stack MERN.

O objetivo principal não foi apenas reproduzir uma interface semelhante ao Airbnb, mas principalmente compreender na prática como construir, estruturar e integrar uma aplicação completa utilizando tecnologias modernas.

Projeto desenvolvido para fins educacionais e de aprendizagem.
